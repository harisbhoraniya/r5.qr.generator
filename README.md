# R5 QR Code Generator

A modern, industrial-grade static QR code generator built with Next.js, React, and Tailwind CSS.

## Features
- **Zero Tracking & 100% Client-Side:** QR matrices are synthesized entirely in your browser.
- **Lifetime Permanent:** Pure static QR codes with no redirects or expiring third-party domains.
- **Multiple Content Types:** URL, PDF File, Instagram, WhatsApp, Plain Text, Wi-Fi, vCard, Email, Phone, SMS.
- **Direct Design Software Integration:**
  - 1-Click Copy / Open in **Adobe Photoshop** (Ctrl + V ready)
  - 1-Click Vector SVG & PDF for **CorelDRAW**
- **Clean Downloads:** Exact tight crop (margin 0) in PNG, JPEG/JPG, WEBP, SVG, and print-ready PDF.
